# Guide Réceptionnaire / Magasinier

Votre rôle : la vie du **colis LCL** en entrepôt — de la réception à la remise au client. Vous ne voyez ni les prix ni les factures : quand SILARIS bloque une remise, c'est lui qui vérifie le règlement pour vous.

## 1. Réception des colis
Ouvrez le dossier (référence fournie par l'agent) → « Enregistrer des colis » : nombre, description, poids unitaire, volume unitaire (CBM). Chaque colis reçoit sa **référence unique** (ex. `TAL-2026-00126-C0001`) et le dossier trace « Réception entrepôt — N colis ».

Comptez et pesez à la réception : ce sont vos chiffres qui font foi ensuite (et qui s'impriment sur l'étiquette).

## 2. Étiquettes
« Imprimer les étiquettes » → PDF, **une étiquette par page (100 × 150 mm)**, prête pour imprimante d'étiquettes. Chaque étiquette porte :
- la référence du colis + **QR code** (le client peut le scanner pour suivre son colis) ;
- **la destination en très gros** sur bandeau sombre (ex. BAMAKO) — votre garde-fou anti-erreur d'empotage ;
- le colisage **n°/total** (ex. COLIS 3/12) — repérez immédiatement un lot incomplet ;
- poids, volume, client (+ téléphone), description, mode (MARITIME LCL / AÉRIEN).

Étiquetez chaque colis dès la réception.

## 3. Empotage (mise en conteneur)
Au chargement : scannez (ou saisissez) chaque colis → action **« Empoté »** + conteneur. Vérifiez que la destination de l'étiquette correspond au conteneur que vous chargez. Le dossier trace « Colis C0003 empoté dans le conteneur MSKU… » — et le client le voit.

L'ordre est verrouillé : un colis non réceptionné ne peut pas être empoté ; un colis empoté ne peut pas être « re-reçu ».

## 4. Dépotage (à destination)
Au dépotage du conteneur : scannez chaque colis → **« Dépoté »**. Les colis passent « Arrivé — sorti du conteneur » pour le client.

## 5. Remise au client — deux contrôles obligatoires
1. **Règlement** : si la facture du dossier n'est pas soldée, SILARIS **refuse la remise** et affiche la facture en attente. Vous n'avez rien à vérifier vous-même — orientez le client vers son gestionnaire. Seul un responsable habilité peut débloquer (dérogation tracée à son nom).
2. **Code de retrait (OTP)** : cliquez « Envoyer le code » → le client reçoit un code à 6 chiffres (valable 30 min, 5 essais max). Il vous le donne, vous le saisissez avec le nom du réceptionnaire → remise confirmée. Le code ne s'affiche jamais sur votre écran : c'est la preuve que la bonne personne retire.

Client sans code ? Vérifiez avec l'agent que son email est correct dans le CRM, puis renvoyez.

## En résumé
`Réception → Étiquettes → Empotage (bon conteneur !) → Dépotage → Remise (facture soldée + code client)` — chaque scan alimente la timeline du dossier et le suivi du client. Vous n'écrivez rien ailleurs : scannez, tout suit.
