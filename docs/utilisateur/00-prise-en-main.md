# SILARIS — Prise en main

## Se connecter
1. Ouvrez l'adresse fournie par votre administrateur et saisissez email + mot de passe.
2. Si la vérification en deux étapes est active : saisissez le code à 6 chiffres de votre application (Google Authenticator, Authy…) ou, en dépannage, un de vos codes de récupération (usage unique).
3. Mot de passe oublié → « Mot de passe oublié » : le lien reçu est valable 60 minutes.

Règles de mot de passe : 12 caractères minimum, majuscule, minuscule, chiffre et caractère spécial.

## Activer la vérification en deux étapes (recommandé)
Profil → Sécurité → Activer la 2FA → scannez le QR code → saisissez le premier code → **conservez les 8 codes de récupération affichés une seule fois** (coffre de mots de passe, jamais en clair dans un email).

## S'orienter
- **Barre latérale** : sections selon vos droits — Opérations (Dossiers, Bookings, Conteneurs, Aérien, Routier), Commercial (CRM, Cotations, Facturation), Ressources (Documents, Administration). Un élément absent = droit non attribué (voir votre administrateur).
- **Recherche globale** (en haut) : référence dossier, n° BL/AWB, conteneur, client.
- **Tableau de bord** : indicateurs temps réel (dossiers actifs, conteneurs, retards, documents manquants, CA du mois), volumes 6 mois, alertes (surestaries, cut-offs sous 48 h, retards), dossiers récents. Rafraîchi automatiquement chaque minute.

## Lire les statuts
| Pastille | Sens |
|---|---|
| Grise | Création / Booking (préparation) |
| Bleue | Départ / Transit / Arrivée |
| Ambre | Douane, ou documents manquants |
| Verte | Livraison / Clôturé / complet |
| Rouge « Retard » | ETA recalculée au-delà du seuil — le client a été notifié |

Petit carré rouge à côté d'une référence = priorité haute/critique.

Sens d'un dossier : **Import**, **Export**, ou **Transit** (transbordement — la marchandise traverse le pays pour être réexpédiée, ex. Abidjan → Bamako).

## Déconnexion
Bouton en haut à droite. Sessions expirées automatiquement après 12 h.
