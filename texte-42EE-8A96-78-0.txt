1. Présentation du projet
Contexte
L’entreprise souhaite disposer d’une plateforme numérique permettant de gérer l’ensemble de ses opérations de transit international.
Le logiciel couvrira :
	●	Transit maritime
	●	Transit aérien
	●	Transit routier
	●	Import
	●	Export
	●	FCL
	●	LCL
	●	Multimodal
L’objectif est de remplacer les traitements manuels (Excel, emails, dossiers papier) par une plateforme centralisée.
⸻
2. Objectifs
Le logiciel devra permettre de :
	●	Gérer les dossiers de transit.
	●	Gérer les clients et fournisseurs.
	●	Automatiser les opérations.
	●	Suivre les conteneurs.
	●	Suivre les colis.
	●	Gérer les documents.
	●	Générer les devis.
	●	Générer les factures (hors comptabilité).
	●	Informer automatiquement les clients.
	●	Offrir un portail client.
	●	Centraliser les données.
	●	Préparer les échanges avec Odoo.
⸻
